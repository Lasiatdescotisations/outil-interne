# outil-interne

Usage interne. Les données saisies restent dans le navigateur.

## Mise en ligne (GitHub Pages)
1. Déposer `index.html` et `.nojekyll` à la racine du dépôt.
2. Réglages → Pages → « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Adresse : `https://<compte>.github.io/<dépôt>/`.

Pour limiter le référencement : nom de dépôt neutre, aucune description ni « topic » sur le dépôt, aucun lien vers la page depuis un site public. La page contient une balise `noindex`.
