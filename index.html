Pour aller plus loin
  • Texte intégral des conventions : base KALI en open data (DILA) et Bulletin officiel des conventions collectives.
  • Accès programmable aux textes officiels : API Légifrance via PISTE (gratuite après inscription) ; kali-data propose un export JSON régulier des conventions.
  • Recoupement des barèmes : simulateurs du Code du travail numérique (licenciement, rupture conventionnelle, retraite) ; leurs règles sont publiées (paquet @socialgouv/modeles-social).
  • Cotisations et contribution patronale sur les indemnités : BOSS, qui précise notamment que le taux de 40 % dépend de la date de fin du contrat.
